# Guía para el compañero: GitHub propio y LLM de su preferencia

Leer [00_LEER_PRIMERO.md](00_LEER_PRIMERO.md) y continuar con la guía 01. Incluye el prompt de arranque para cualquier LLM en la guía 08.

Estas instrucciones se ejecutan sobre el **kit de transferencia** entregado como ZIP, cuya estructura es 00 Code/web, emisor, integración y herramientas. El repositorio actual conserva su estructura histórica 00 Code/visor. No ejecutar las rutas del kit directamente sobre este repo ni reutilizar esta cuenta como destino. El ZIP contiene la copia configurable, la base HTML conectada y las instrucciones; no se publica aquí el HTML base en claro ni ninguna credencial.

El acceso de la LLM al repositorio y la autenticación del PC emisor son dos conexiones diferentes. Primero usar la cuenta del compañero y comprobar ambas.
